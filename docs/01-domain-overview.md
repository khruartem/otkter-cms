# Что вообще делает эта система?

CMS предназначена для управления контентом сайта «Открытая Территория». Система позволяет администратору создавать, редактировать, публиковать и удалять проекты, услуги, персон и товары, а также управлять связанными категориями, медиафайлами и другой информацией. Публичный сайт использует опубликованные данные CMS для отображения контента посетителям.

## Ограничения

- CMS предназначена для одного администратора;
- публичные пользователи CMS не используют;
- основной consumer данных — публичный сайт.
