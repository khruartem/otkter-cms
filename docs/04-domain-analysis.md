# Описание сущностей 
Сущности можно разделить на следующий список:
* Проект
* Услуга
* Персона
* Категория
## Сущность ОТ
### Описание
Родительская сущность, которая описывает основные атрибуты проекта, услуги и сотрудника
### Список атрибутов
Ниже список атрибутов для сущности ОТ:
| Атрибут | Обязательность | Описание |
| :--- | :--- | :--- |
| ИД | Да | Идентификатор сущности uuid |
| Тип | Да | Описывает тип сущности (проект, услуга, сотрудник) |
| Slug | Да | Код сущности, может использоваться для генерации ссылки (например: https://otkter.ru/projects/esenin/, где projects - тип сущности: проект, esenin - код проекта) |
| Группа | Да | Группа, в которую входит сущность, понадобится для отображения в слайдерах |
| Заголовок | Да | Для отображения заголовка в карточке и на отдельной странице |
| Короткое описание | Да | Для отображения текста в карточке сущности |
| Дополнительное описание | Нет | Для отображения пояснительного текста в карточке сущности |
| Основное описание | Нет | Для отображения текста просмотра страницы с сущностью |
| Картинка | Да | Для отображения картинки в карточке сущности |
| Превью | Нет | Для отображения превью при формировании ссылки на сущность |
| Иконка | Да | Сжатое по качеству изображение для отображения иконки сущности иконка всегда маленькая по размеру 44х44 примерно |
| Категории | Нет | Список категорий сущности для отображения в карточке. Категории могут содержать флаг "Обратить внимание", тогда весь список отображается в другой цветовой гамме и имеет иконку в самом начале |
| Постер | Нет | Постер, который отображается на отдельной странице сущности. Обычно отличается от картинки в карточке |
| Фотографии | Нет | Список фотографий, которые отображаются на отдельной странице сущности. По умолчанию отображается превью фото, по клику отображается полноразмерное фото |
| Детальная информация | Нет | Отображается на отдельной странице сущности. Состоит из таких блоков, как иконка, тип (инфо о сотруднике, проекте/услуге, СМИ), лэйбл, который отображается, сама инфа, внешняя ссылка |
| Кнопки | Нет | Отображается на отдельной странице сущности. Кнопки действий: заказа услуги или покупки билетов |
| Флаг "Основная" | Да | Основные сущности отображаются на главной странице сайта, по умолчанию - ложь |
| Флаг "Активная" | Да | Активная сущность связана с действующей услугой или активным проектом, такие сущности отображаются штатно, если сущность неактивна, то там появляются лейбл завершено и тд. По умолчанию - правда |
