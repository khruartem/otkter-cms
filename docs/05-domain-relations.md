# Связи между сущностями

## Проект

- Проект связан с 0..N категориями.
- Проект связан с 0..N персонами через сущность «Персона в проекте».
- Проект содержит 0..N характеристик.
- Проект содержит 0..N фотографий.
- Проект содержит 0..N кнопок.
- Проект содержит 0..N упоминаний в СМИ.
- Проект содержит 0..N событий истории.

## Услуга

- Услуга связана с 0..N категориями.
- Услуга связана с 0..N персонами через сущность «Персона в услуге».
- Услуга содержит 0..N характеристик.
- Услуга содержит 0..N фотографий.
- Услуга содержит 0..N кнопок.
- Услуга содержит 0..1 CTA.

## Персона

- Персона связана с 1..N категориями.
- Персона может быть связана с 0..N проектами.
- Персона может быть связана с 0..N услугами.
- Персона может иметь 0..N социальных сетей.
- Персона содержит 0..N упоминаний в СМИ.
- Персона содержит 0..N фотографий.

## Мерч (товар)

- Товар связан с 1..N категориями.
- Товар связан с 0..N со списками характеристик по товару.
- Товар содержит 0..N фотографий.
- Товар содержит 0..N кнопок.

## Категория

Владельцем категории может быть ровно одна сущность:

- Проект
- Услуга
- Персона
- Мерч

## Характеристика

Владельцем характеристики может быть ровно одна сущность:

- Проект
- Услуга

## Блок характеристики

- Блок характеристики связана с 1..1 Характеристикой.

## Упоминание в СМИ

Владельцем упоминаний в СМИ может быть ровно одна сущность:

- Проект
- Персона

## История

- Событие истории связано с 1..1 проектом.

## CTA

- CTA связано с 1..1 услугой.

## Персона в проекте

- Персона в проекте связана с 1..1 проектом.
- Персона в проекте связана с 1..1 персоной.

## Персона в услуге

- Персона в услуге связана с 1..1 услугой.
- Персона в услуге связана с 1..1 персоной.

## Список характеристик по товару

- Список характеристик связана с 1..1 товаром.
- Список характеристик связана с 1..N характеристиками.

## Характеристика по товару

- Характеристика связана с 1..1 списком характеристик.
