# Глоссарий

| Термин | Определение |
| :--- | :--- |
| Проект | Мероприятие или инициатива, реализуемая Открытой территорией. Проект может содержать категории, фотографии, характеристики, персон, действия, упоминания в СМИ и события. |
| Услуга | Услуга, оказываемая Открытой территорией. Может содержать фотографии, характеристики, персон, действия и CTA. |
| Персона | Человек, участвующий в деятельности Открытой территории. Персона может быть связана с проектами и услугами, иметь категории, фотографии, социальные сети и упоминания в СМИ. |
| Мерч (товар) | Фирменная продукция Открытой территории, доступная для отображения и покупки на публичном сайте. |
| Категория | Переиспользуемый классификационный признак для группировки и маркировки проектов, персон и товаров. |
| Галерея | Набор фотографий, связанных с конкретной сущностью. Галерея может принадлежать проекту, услуге, персоне или товару. |
| Фото | Элемент галереи, содержащий ссылку на изображение и принадлежащий ровно одной сущности: проекту, услуге, персоне или товару. |
| Изображение | Медиа-объект, хранящий информацию о физическом файле в объектном хранилище. Другие сущности используют изображения для карточек, постеров, превью, иконок и фотографий. |
| Иконка | Изображение небольшого размера, используемое для визуального представления сущности или элемента интерфейса. |
| Иконка категории услуги | Изображение, используемое для отображения услуги в специальном слайдере категорий. Иконка обязательна для публикации услуги. |
| Действие | Элемент пользовательского действия, содержащий ссылку, текст, тип и необязательную иконку. Действие может принадлежать проекту, услуге или товару. |
| Тип действия | Вариант визуального представления действия. Поддерживаются типы `primary` и `secondary`. |
| CTA | Call to Action — дополнительный призыв к действию, используемый в услуге. Одна услуга может иметь не более одного CTA. |
| Социальная сеть | Ссылка на внешний профиль или ресурс, принадлежащая конкретной персоне. Может содержать иконку и текстовое представление. |
| Характеристика | Дополнительная структурированная информация о проекте или услуге. Содержит заголовок, набор значений и может содержать иконку. |
| Упоминание в СМИ | Информация о публикации в СМИ: изображение, название источника, текст и ссылка на исходный материал. Упоминание может быть связано с несколькими проектами и персонами. |
| Событие | Конкретное проведение проекта в определённом месте и времени. Может содержать дополнительную подпись и признак активности. |
| Активное событие | Событие проекта, для которого установлен флаг активности. Значение флага задаётся администратором. |
| Персона в проекте | Связь между проектом и персоной. Может содержать роль персоны в проекте и дополнительный пояснительный текст. Одна персона может иметь несколько ролей в одном проекте. |
| Персона в услуге | Связь между услугой и персоной. Может содержать роль персоны в услуге и дополнительный пояснительный текст. |
| Список характеристик по товару | Группа характеристик товара, объединённых одним названием, например «Размер», «Объём» или «Цвет». |
| Характеристика по товару | Отдельное значение внутри списка характеристик товара. Может содержать текст и цвет. |
| Черновик (`draft`) | Состояние сущности, при котором она не отображается на публичном сайте и может содержать неполные данные. |
| Опубликовано (`published`) | Состояние сущности, при котором она доступна публичному сайту. Перед публикацией выполняется проверка обязательных данных. |
| Публикация | Операция перевода сущности из состояния `draft` в `published` после успешной проверки требований к публикации. |
| Статус публикации | Независимое состояние публичной доступности проекта, услуги, персоны или товара. Поддерживаются значения `draft` и `published`. |
| Основной проект | Проект с установленным флагом `is_main`. Опубликованный основной проект отображается в секции «Проекты» на главной странице сайта. |
| Активный проект | Проект с установленным `is_active = true`, считающийся действующим. |
| Завершённый проект | Проект с `is_active = false`. Завершение проекта не снимает его с публикации автоматически. |
| Обратить внимание на категории | Специальный признак проекта (`category_is_attention`), изменяющий визуальное отображение всего блока категорий проекта. Не является свойством отдельной категории и не влияет на публикацию. |
| Требуются характеристики товара | Признак `requires_characteristics`. Если он установлен, товар нельзя опубликовать без хотя бы одного непустого списка характеристик. |
| Доступность товара для покупки | Признак `is_available`, определяющий возможность покупки товара. Не влияет на публикацию: опубликованный недоступный товар остаётся видимым на сайте, но купить его нельзя. |
