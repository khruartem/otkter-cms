# Глоссарий
| Термин | Определение |
| :--- | :--- |
| Проект | Мероприятие или инициатива, которое делает ОТ |
| Услуга | Услуга, оказываемая ОТ |
| Персона | Человек/персона, которая задействована в деятельности ОТ |
| Категория | Классификационный признак, используемый для группировки и маркировки контента |
| Галерея | Коллекция изображений, фотографий |
| Кнопка | Элемент действия, связанный с переходом по ссылке или выполнением пользовательского сценария |
| Характеристики | Набор дополнительной структурированной информации о сущности, отображаемой на её странице. Состав характеристик зависит от типа сущности и может включать организатора, партнёров, адрес, дату, стоимость, телефон и другие сведения |
| Соц. сети | Набор соц.сетей для отображения на сайте |
| Партнер | Партнер ОТ, который помогает в проектах |
| Мерч | Фирменная продукция ОТ |
| Черновик | Неопубликованная версия |
| Публикация | Процесс перевода сущности из состояния черновика в опубликованное состояние, после которого она становится доступна публичному сайту |
| Состояние | Признак жизненного цикла сущности, определяющий, является она действующей или архивной |
| Основной признак | Признак, определяющий необходимость отображения сущности на главной странице сайта |
| Архивный/Действующий признак | Признак означает завершенность/продолжительность, влияет на отображение карточки |
| CTA | CTA (Call to Action) — дополнительный призыв к действию, сопровождающий основную кнопку или действие |
| Упоминание в СМИ | Ссылка на статью о сущности |
| Событие | Конкретное проведение проекта или услуги в определённом месте и времени |
| Активное событие в истории проекта | Флаг, что событие активно |
| Иконка | Сжатое по качеству изображение для отображения иконки сущности. Иконка всегда маленькая по размеру 44х44 примерно |
| Признак "Обратить внимание" | Признак категории, если есть, тогда весь список отображается в другой цветовой гамме и имеет иконку в самом начале |
| Список характеристик по товару | Группа характеристик, объединенных одной тематикой и имеющая одно название (например: размер, объем, цвета и тд) |
