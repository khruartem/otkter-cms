# Варианты использования

Документ описывает основные действия администратора в CMS.

## Администратор

### Общее

- Войти в систему по паролю.
- Выйти из системы.

## Проекты

- Просматривать список проектов.
- Просматривать проекты по состоянию: все, действующие, завершённые.
- Создать черновик проекта.
- Редактировать проект.
- Опубликовать черновик проекта.
- Снять проект с публикации и вернуть его в состояние черновика.
- Удалить проект в состоянии черновика.
- Управлять порядком отображения проектов.
- Управлять признаком «Основной».
- Управлять состоянием проекта: действующий / завершённый.
- Управлять признаком «Обратить внимание на категории».
- Управлять категориями проекта.
- Управлять информацией для карточки проекта.
- Управлять информацией для страницы проекта.
- Управлять галереей проекта.
- Управлять персонами проекта и их ролями.
- Управлять характеристиками проекта.
- Управлять действиями проекта.
- Управлять событиями проекта.
- Управлять упоминаниями проекта в СМИ.
