# Бизнес-правила и ограничения

## Общие

- Нельзя опубликовать сущность без обязательных данных.
- Slug должен быть уникальным в рамках типа сущности.
- Опубликованную сущность можно редактировать.
- После изменения опубликованной сущности изменения должны отображаться на публичном сайте.
- Ни одна root-сущность (`Project`, `Service`, `Person`, `Product`) не может быть опубликована без хотя бы одной категории.
- Товар не может быть опубликован без цены.
- Для товара, требующего характеристик, публикация невозможна без хотя бы одного непустого списка характеристик.
- Созданный список характеристик не может быть пустым у опубликованного товара.

## Видимость и состояние проекта

`publication_status`, `is_main` и `is_active` описывают разные аспекты состояния проекта и не заменяют друг друга.

#### `publication_status`

Определяет доступность проекта на публичном сайте.

- `draft` — проект не отображается на публичном сайте;
- `published` — проект доступен на публичном сайте.

#### `is_main`

Определяет отображение опубликованного проекта в секции «Проекты» на главной странице сайта.

- `true` — опубликованный проект отображается на главной странице;
- `false` — проект не отображается на главной, но остаётся доступным на собственной странице при `publication_status = published`.

#### `is_active`

Определяет бизнес-состояние проекта.

- `true` — проект действующий;
- `false` — проект завершён.

Завершённый проект не снимается с публикации автоматически.

Если `publication_status = published` и `is_active = false`, проект остаётся доступным на публичном сайте, но отображается в визуальном состоянии завершённого проекта и содержит соответствующую отметку на странице проекта.
