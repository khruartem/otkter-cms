# Варианты использования
Что можно делать в системе?
## Администратор
### Общее
* Войти в систему по паролю.
* Выйти из системы.
### Проекты
* Просматривать проекты по категориям: все, архивные, действующие.
* Создать черновик проекта.
* Опубликовать черновик проекта.
* Снять проект с публикации - вернуть в черновик.
* Удалить проект (черновик).
* Отредактировать проект (черновик):
  * Задать порядок отображения проекта.
  * Указать архивный проект или действующий.
  * Задать формат проекта (несколько форматов).
  * Отметить, что проект будет отображаться на главной странице.
  * Заполнить основную информацию для карточки проекта.
  * Загрузить изображение для карточки проекта.
  * Загрузить изображение для постера проекта.
  * Загрузить галерею для проекта.
  * Заполнить детальную информацию по проекту.
  * Добавить персон, которые работали над проектом.
  * Добавить кнопки.
  * Добавить упоминания в СМИ.
### Услуги
* Создать черновик услуги.
* Опубликовать черновик услуги.
* Снять услугу с публикации - вернуть в черновик.
* Удалить услугу (черновик).
* Отредактировать услугу (черновик):
  * Задать порядок отображения услуги.
  * Задать иконку услуги.
  * Заполнить основную информацию для карточки услуги.
  * Загрузить изображение для карточки услуги.
  * Загрузить изображение для постера услуги.
  * Загрузить галерею для услуги.
  * Заполнить детальную информацию по услуге.
  * Добавить персон, которые предоставляют услугу.
  * Добавить кнопки.
  * Добавить уникальное предложение.
  * Добавить упоминания в СМИ.
### Персоны
* Создать черновик персоны.
* Опубликовать черновик персоны.
* Снять персону с публикации - вернуть в черновик.
* Удалить персону (черновик).
* Отредактировать персону (черновик):
  * Задать порядок отображения персоны.
  * Задать контактную информацию персоны.
  * Заполнить основную информацию для карточки персоны.
  * Загрузить изображение для карточки персоны.
  * Загрузить изображение для постера персоны.
  * Загрузить галерею для персоны.
  * Добавить кнопки.
  * Добавить упоминания в СМИ.
