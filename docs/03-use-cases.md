# Варианты использования

Что можно делать в системе?

## Администратор

### Общее

- Войти в систему по паролю.
- Выйти из системы.

### Проекты

- Просматривать проекты по категориям: все, архивные, действующие.
- Создать черновик проекта.
- Опубликовать черновик проекта.
- Снять проект с публикации - вернуть в черновик.
- Удалить проект (черновик).
- Управлять порядком отображения проекта.
- Управлять состоянием проекта (архивный/действующий).
- Управлять категориями проекта (несколько форматов).
- Управлять информацией для карточки проекта.
- Управлять информацией для страницы проекта.
- Управлять галереей для проекта.
- Управлять персонами для проекта.
- Управлять характеристиками проекта.
- Управлять кнопками проекта.
- Управлять историей проекта.
- Управлять упоминаниями в СМИ.
