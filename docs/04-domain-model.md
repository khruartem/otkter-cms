## Услуга
### Список атрибутов
| Атрибут | Описание |
| :--- | :--- |

| Заголовок | Для отображения заголовка в карточке и на отдельной странице |
| Короткое описание | Для отображения текста в карточке сущности |
| Основное описание | Для отображения текста просмотра страницы с сущностью |

| Картинка | Для отображения картинки в карточке сущности |
| Постер | Постер, который отображается на отдельной странице сущности. Обычно отличается от картинки в карточке |
| Превью | Для отображения превью при формировании ссылки на сущность |
| Иконка | Сжатое по качеству изображение для отображения иконки сущности иконка всегда маленькая по размеру 44х44 примерно |

| Категории | Список категорий сущности для отображения в карточке |

| Характеристика | Содержит основные харакетристики по услуге в виде блоков |
| Персоны | Персоны, которые задействованы в услуге |

| Фотографии | Нет | Список фотографий, которые отображаются на отдельной странице сущности |

| Кнопки | Нет | Отображается на отдельной странице сущности. Кнопки действий: заказа услуги или покупки билетов |
| CTA | Нет | CTA для кнопки |

| Флаг "Основная" | Да | Основные сущности отображаются на главной странице сайта, по умолчанию - ложь |
| Флаг "Активная" | Да | Активная сущность отображаются штатно, если сущность неактивна, то там появляются лейбл завершено и тд. По умолчанию - правда |
| Порядок | Нет | Порядок для отображения на главной странице |
