# Описание сущностей 
Сущности можно разделить на следующий список:
* Проект
* Услуга
* Персона
* Категория
* Мерч (товар)
## Проект
### Список атрибутов
| Атрибут | Обязательность | Описание |
| :--- | :--- | :--- |

| Slug | Да | Код сущности, может использоваться для генерации ссылки (например: https://otkter.ru/projects/esenin/, где projects - тип сущности: проект, esenin - код проекта) |
| Заголовок | Да | Для отображения заголовка в карточке и на отдельной странице |
| Короткое описание | Да | Для отображения текста в карточке сущности |
| Основное описание | Нет | Для отображения текста просмотра страницы с сущностью |

| Картинка | Да | Для отображения картинки в карточке сущности |
| Постер | Нет | Постер, который отображается на отдельной странице сущности. Обычно отличается от картинки в карточке |
| Превью | Нет | Для отображения превью при формировании ссылки на сущность |
| Иконка | Да | Сжатое по качеству изображение для отображения иконки сущности иконка всегда маленькая по размеру 44х44 примерно |

| Категории | Нет | Список категорий сущности для отображения в карточке |

| Характеристика | Нет | Содержит основные харакетристики по проекту в виде блоков |
| Персоны | Нет | Персоны, которые задействованы в проекте |
| Упоминания в СМИ | Нет | Упоминания о проектах в СМИ |

| Фотографии | Нет | Список фотографий, которые отображаются на отдельной странице сущности |

| Кнопки | Нет | Отображается на отдельной странице сущности. Кнопки действий: заказа услуги или покупки билетов |

| История | Нет | История по проекту |

| Флаг "Основная" | Да | Основные сущности отображаются на главной странице сайта, по умолчанию - ложь |
| Флаг "Активная" | Да | Активная сущность отображаются штатно, если сущность неактивна, то там появляются лейбл завершено и тд. По умолчанию - правда |
| Порядок | Нет | Порядок для отображения на главной странице |
