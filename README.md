# OTKTER CMS

> Content Management System для управления сайтом-хабом Открытой Территории.

## 📖 О проекте

OTKTER CMS — это административная панель для управления контентом сайта Открытой Территории.

Проект разрабатывается с нуля как полноценное Fullstack-приложение с акцентом на архитектуру, проектирование и качество кода.

Основная цель проекта — не только создать рабочую CMS, но и пройти полный цикл разработки современного веб-приложения:

- анализ предметной области;
- проектирование базы данных;
- проектирование REST API;
- разработка backend;
- разработка frontend;
- деплой приложения.

---

## 🎯 Цели проекта

- Изучить архитектуру backend-приложений.
- Научиться проектировать REST API.
